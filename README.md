# ☁️ Fra kassen til skyen – mit CV på Microsoft Azure

Min personlige CV-hjemmeside, hostet på **Azure Static Web Apps**. Hver gang jeg ændrer koden her på GitHub, bygger og udgiver **GitHub Actions** automatisk den nye version (CI/CD).

## Hvad jeg har brugt

* **Azure Static Web Apps** (gratis plan) til hosting med HTTPS
* **GitHub Actions** til automatisk deployment
* **HTML, CSS og JavaScript** – ingen frameworks
* `staticwebapp.config.json` med sikkerheds-headers
